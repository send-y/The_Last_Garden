## Возможности

Runtime-addon в `game/addons/garden_bridge` работает в debug-игре и отдаёт
ограниченные JSON-ответы. Python 3.11 предоставляет MCP stdio и CLI без
дополнительных пакетов. Локальная `.codex/config.toml` настроена, проверена
через `codex mcp get garden_bridge --json` и исключена из Git как машинная
конфигурация. Переносимый пример находится рядом с сервером.

Пять инструментов: обнаружение живых сессий, состояние симуляции, дерево UI
с геометрией/обрезанием, ошибки и backtrace, скриншот с JSON того же кадра.
Нет сетевого порта, выполнения кода, изменения мира или сейва. Обмен и
снимки находятся в игнорируемой `.garden_bridge/`. Несколько живых игр
требуют явного `session_id`; старые сессии исключаются по heartbeat.
Мост продолжает отвечать при игровой паузе. Обычные изолированные тесты
и release его отключают. Опция `--garden-bridge-off` отключает явно.

[Инструкция и команды](../../tools/garden_bridge/README.md).

## Независимое ревью

Свежий read-only reviewer проверил `3c331c6..a0d37d7` и нашёл три P2:
ошибка преобразования IPC-параметра оставляла `_busy`, отсутствие frame_post_draw
блокировало мост, JSON `[]` в manifest ломал discovery исправных игр.
Все три воспроизведены тестами и исправлены за один проход. Финальный набор
headless/graphics/suspended-render после исправлений прошёл. Второго review
не было; исправления проверены координатором. Отложенных замечаний нет.

Reviewer не доказывал реальную многопоточную конкуренцию logger, все изменения
полного state и остановленный renderer. Последние два случая после review
проверены отдельным host; многопоточный стресс не запускался. Общий буфер Logger
защищён Mutex, но это не отдельное доказательство поведения всех потоков движка.

## Границы первой версии

Уже открытый процесс игры нужно перезапустить для загрузки addon. Для новых
MCP-инструментов текущему чату может понадобиться переподключение MCP/перезапуск
Codex. В этой сессии подтверждены конфигурация CLI и настоящий stdio-обмен,
а не автоматическое обновление списка инструментов уже открытого чата.

Ранние ошибки компиляции/autoload до установки Logger читаются из обычного
лога Godot. Снимка нет в headless; остановленный debugger может прекратить
heartbeat и обработку команд. Дерево имеет явные лимиты/признак усечения;
состояние инструмента — полезная проекция симуляции, не новый игровой сейв.
Мост — runtime-addon с MCP, отдельная панель EditorPlugin в v0.1 не добавлялась.
