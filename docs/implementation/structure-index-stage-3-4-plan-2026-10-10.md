# Индекс: склад, мебель, свет и обновления представления

> Исполнение inline через `superpowers:executing-plans`; продолжение уже согласованного дизайна.

**Goal:** убрать оставшиеся глобальные обходы построек и обновления карты из-за изменений NPC, сохранив игровое состояние.
**Architecture:** склад читает примитив индекса, мебель и свет кешируют по идентичности индекса и версии. Представление разделяется на независимые canvas-слои; снимки только визуальных входов изолированы от живого состояния.
**Tech Stack:** Godot 4.7, GDScript, прежний Windows CPU-измеритель.
**Spec:** [согласованный дизайн](structure-index-design-2026-10-10.md), разрешение пользователя «Ну давай» после предложения разделить обновления.

## Ограничения

- Правила симуляции, сейв и контент не меняются. Потоки в этом инкременте не вводятся.
- Изменения остаются в текущей ветке: необходимые стресс-сценарии и индекс ещё не закоммичены. Пуш/коммит не входят в запрос.
- При неизменном запросе нет сериализации или сверки всего массива построек.
- Один финальный независимый просмотр кода. Замеры строго отдельно от тестов.

## Задачи

1. `StorageSystem`: `get_storage_grid_size` и `_storage_cell_has_floor` читают `structure_index.has_floor`. Проверка размера до/после пола и нулевых обращений к геометрии каталога.
   - [x] RED → GREEN `indexed_consumers_test --only=storage`; текущие складские интеграции.
   - [x] Отдельный `storage-redraw-30` до дальнейшей переработки представления.
2. `FurnitureSystem`, `LightingField`, `StructureLayer`: идентичность индекса + версии до получения копий. При пересборке мебель/свет используют списки типов; световые команды остаются немедленно видны логическим запросам.
   - [x] RED → GREEN: ноль сериализаций, фактическое место еды, снос стола, переключение факела и два мира с одинаковыми версиями.
   - [x] Свет: 30 настоящих NPC включают факелы вечером; отчёт содержит фактическое покрытие. Последовательное включение/чтение проверяется отдельно.
3. `FirstNightWorld`, новый `WorldPresentationLayer`: статический фон, комнаты, дом, зоны склада, предметы склада, грядки, сетка и выделение обновляются независимо. Складское представление группирует предметы по клетке одним проходом; логические запросы склада сохраняют прежние правила.
   - [x] RED → GREEN: движение/потребности NPC не вызывают world/structure rebuild; перенос, рост/высыхание, строительство, выделение и reload отображаются.
   - [x] Полный прежний набор проверок, guard, сравнение экспортов с эталоном, work-30/sleep-30/кадровые замеры.

## Review Focus

Идентичность мира при равных версиях; порядок слоёв относительно полов/персонажей;
истечение влажности без изменения записей грядки; состояние иконки предмета на складе;
логическая освещённость между последовательными включениями.

## Ledger

Ruling: используем текущую рабочую копию и короткий план без нового согласования — пользователь одобрил исполнение, дизайн уже принят; цена ошибки границ проверяется отдельными замерами и эталоном состояния.
Ruling: вместо разнесения всего state_changed на новые игровые сигналы фильтруем визуальные входы на стороне слоёв — это не требует менять каждый источник мутации; небольшие сравнения визуальных данных остаются на событие, а не в горячих запросах.

Complete: все три задачи реализованы; 27 наборов, source guard, равенство трёх
экспортов и пять нативных сценариев прошли. Финальный read-only reviewer
не обнаружил actionable findings. Это не означает достижение 100 FPS.

Outcome: [измеренный результат](structure-index-consumers-result-2026-10-10.md).
Вечер покрывает 30/30 настоящих включений и обнаруживает 4,17 с в observe-home-projects.
Следующие расходы оставлены измеренными приоритетами, а не автоматически
добавленными оптимизациями текущего инкремента.

Incident: ранний world-presentation test записал фикстуру в основной сейв.
Тест теперь имеет собственный SaveStore; дополнительный запуск оставил
SHA256 основного файла и `.bak` неизменными. Прежний сейв не восстановлен,
поскольку текущие копии уже содержат фикстуру. Пользователь уведомлён.

Review coverage: тесты и статический просмотр не доказывают эквивалентность
всех пикселей, долговременное прохождение или все matching-version reload
сочетания. Прежний порядок слоёв сохранён, включая прежние перекрытия.
