# Контрольная точка перед следующей вехой — 10 октября 2026

Пакет фиксирует накопленную реализацию в ветке `codex/storage-zones`:

- Постоянный мир, разделение симуляции на системы, фермерство и физическое
  состояние персонажей.
- Жильё и спальные места, полезная мебель, случайные жители, знакомство и разговоры.
- Самостоятельное обустройство личного и совместного жилья, защита запасов,
  просьбы о расширении, производство досок для личных проектов.
- Работа жителей, интерфейс инвентаря и предмет в руке, разбор построек,
  работающие двери, соединения стен, удаление кустов и проход через персонажей.
- Исправления обновлений при подборе и смене минуты, строка FPS.
- Данные контента, локализация, тесты, графика и её исходники, документация
  и исторические свидетельства разработки.

Это сохранение текущего рабочего состояния. Работа с NPC приостановлена
по решению автора перед следующей вехой; все возможные механики NPC этим
пакетом не исчерпаны. Свободный ввод реплик остаётся заглушкой. Планета,
генерация локальной карты по её гексу и первый рейс в Бездну впереди.
Предложенный дизайн расширения контента ожидает просмотра и ещё не реализован.

## Проверка перед публикацией

- [59 существующих проверок](../../artifacts/checkpoint-2026-10-10/verification.json):
  основной набор симуляции, самостоятельные тесты, тестовые сцены и запуск игры.
  Четыре проверки пикселей запускаются с графическим рендерером.
- [Проверка копии из индекса Git без локального кэша](../../artifacts/checkpoint-2026-10-10/clean-verification.json):
  импорт, основной набор, UI производства жителя и запуск игры.
- [Пять проверок при отсутствующей записи WorldSimulation в кэше классов](../../artifacts/world-class-loading-2026-10-08/registry-checks.json).

При первом импорте чистой копии Godot читает ссылку на `core.ru.translation`
раньше генерации перевода из CSV. В bootstrap-логе сохранены эти сообщения;
повторный импорт и дальнейшие запуски проверяются уже без таких ошибок.

В тесте миграции жилья исправлено устаревшее ожидание версии 34: сохранение
из версии 33 должно перейти к текущему формату, сейчас 36. Проверки сохранности
назначений и восстановления повреждённых политик сохранены. В новых модулях
также убраны пробелы в конце строк; поведение игры при этом не менялось.

Автоматические проверки не заменяют длительный плейтест и не подтверждают
отсутствие просадок ниже 100 FPS. Исторические логи с ошибками относятся
к предыдущим попыткам и исправлениям; свежие результаты находятся по ссылкам выше.
