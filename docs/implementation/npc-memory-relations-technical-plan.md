# Технический план 2D: память, отношения и контекстная реплика

- **Инкремент:** 2D среза 2 «Один самостоятельный сосед».
- **Рабочая ветка:** `codex/npc-memory-relations`.
- **Зависимости:** 2C слит в `main` через PR #8.
- **Статус:** техническая реализация завершена; автоматические проверки пройдены, ручной плейтест ожидается.
- **Формат проверки:** одно подтверждённое воспоминание после совместной стройки и одна подготовленная реплика, затем общий плейтест среза 2.

## Цель

Проверить, становится ли подтверждённое совместное действие частью истории отношений, а не исчезает после завершения команды.

После того как Мира по принятой просьбе действительно завершает стену, симуляция создаёт одно воспоминание. Следующая беседа один раз использует подходящую подготовленную реплику, а Mechanics Lab показывает вычисленное влияние события на доверие, тепло и уважение.

## Подтверждённое событие

Воспоминание `core:first_shared_wall` возникает только при выполнении всей цепочки:

1. Игрок разместил настоящий чертёж стены.
2. Мира приняла структурированную просьбу 2C.
3. Мира дошла до места и отработала необходимое игровое время.
4. Симуляция успешно превратила этот чертёж в готовую конструкцию.

Debug-завершение стены, отказ, отмена чертежа или недоделанная работа воспоминание не создают.

## Состояние памяти

Save v9 добавляет известному NPC коллекцию `memories`. Первая запись хранит только стабильные данные:

```text
memory_id: core:first_shared_wall
event_id: core:shared_wall_completed
subject_id: core:player
kind_id: core:shared_experience
source_id: core:personal_experience
valence_id: core:positive
day: int
minute: int
salience: float
relationship_effects:
  trust: float
  warmth: float
  respect: float
acknowledged: bool
target_cell: [int, int]
```

Видимая фраза не хранится в сохранении. `event_id` связывается с ключом локализации через определение NPC.

## Отношения как производная памяти

Доверие, тепло и уважение не изменяются отдельной командой и не дублируются в save. Запрос отношений суммирует влияние нормализованных воспоминаний и ограничивает каждую ось диапазоном `-100..100`.

Для первой гипотезы совместная стена даёт небольшой положительный эффект:

- доверие `+1`;
- тепло `+2`;
- уважение `+1`.

Значения видны только в Mechanics Lab и не считаются окончательным балансом.

## Контекстная реплика

После появления воспоминания следующая беседа Миры выбирает подготовленную реплику `dialogue.core.first_neighbor.shared_wall`. После показа запись получает `acknowledged: true`, но не удаляется. Последующие разговоры возвращаются к обычной повторной реплике.

Генеративная модель не участвует в выборе, формулировке или подтверждении события.

## Границы

В 2D входят:

- одно личное воспоминание Миры;
- одна положительная комбинация трёх осей отношений;
- save/load и безопасная нормализация;
- одна одноразовая контекстная реплика;
- диагностический сценарий Mechanics Lab;
- автоматическая проверка отсутствия ложных воспоминаний.

Не входят:

- угасание остроты со временем;
- отрицательные воспоминания и восстановление доверия;
- память о словах или свободном тексте;
- передача сведений другим NPC;
- отношения NPC между собой;
- постоянные числовые шкалы в обычном интерфейсе;
- генеративная модель;
- несколько конкурирующих контекстных реплик.

## Критерии готовности

1. Воспоминание создаётся только после подтверждённого завершения стены Мирой.
2. Одна и та же первая совместная стена не создаёт дубликаты.
3. Отказ, отмена, debug-завершение и незавершённая работа не создают запись.
4. Память переживает JSON round-trip, а save v8 мигрирует в v9 с пустым списком.
5. Повреждённые записи отбрасываются без повреждения состояния NPC.
6. Отношения вычисляются из памяти и не хранят отдельную изменяемую истину.
7. Следующий разговор использует контекстную реплику ровно один раз.
8. Повторный разговор возвращается к обычной реплике Миры.
9. Mechanics Lab показывает событие и точные значения трёх осей.
10. Одинаковое состояние даёт одинаковую память, отношения и реплику.

## Результат реализации

- Save v9 хранит нормализованные воспоминания NPC и безопасно мигрирует save v8.
- Завершение настоящего чертежа Мирой создаёт `core:first_shared_wall`; отмена, незавершённая работа и debug-завершение запись не создают.
- Доверие `+1`, тепло `+2` и уважение `+1` вычисляются из памяти и доступны через симуляцию и `Session`.
- Следующая беседа один раз использует `dialogue.core.first_neighbor.shared_wall`, после чего возвращается обычная повторная реплика.
- Mechanics Lab содержит сценарий `После совместной стены` с готовым состоянием дня 2, 07:20 и диагностикой памяти и отношений.
- Импорт проекта, полный набор тестов, основная сцена, лабораторный сценарий и интеграционная проверка коллизии проходят в Godot 4.7.

## Ручная проверка

1. Открыть Mechanics Lab и выбрать сценарий `После совместной стены`.
2. Убедиться, что диагностика показывает одно воспоминание и значения `Д 1 / Т 2 / У 1`.
3. Поговорить с Мирой: первая реплика должна быть о крепкой стене и доме.
4. Поговорить повторно: должна вернуться обычная повторная реплика.
5. Убедиться, что число воспоминаний и значения отношений не изменились.
