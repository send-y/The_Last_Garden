# Свойства предметов: единый источник пищевой ценности

11 октября 2026. Первый результат подготовки расширяемости контента.
Локальная контрольная точка до реализации — `4310641`; пуш не выполнялся.
Новая часть остаётся отдельными изменениями поверх неё.

## Что работает

Пищевая ценность хранится в `items.json`, в объекте `food` с полями
`satiety`/`energy`. Каталог подготавливает свойства один раз, запрос возвращает
отдельный маленький словарь. Меню инвентаря, питание игрока и NPC, место еды
за столом, карточка обеспеченности и предпросмотр сна используют один источник.
Дубли пищевых значений удалены из `crops.json`.

Новый съедобный предмет может не принадлежать культуре. Энергия может быть
нулевой при положительной сытости. Такая еда расходуется физически и не
восстанавливает выспанность. Съедобность не даёт способности извлекать семена:
особые ягоды и продукты культур проверяются отдельно. Старые диапазоны
семян, доступ через изучение и последовательность RNG сохранены.

Версии каталога предметов/пищевых свойств — 4/1. Неизвестные версии,
неизвестные ключи внутри `food`, отсутствие обязательных полей и неверные
числа дают ошибку с файлом, ID и полем. Старый формат предметов 3 читается
без пищевого свойства; для `food` требуется явный переход на новый формат.
Формат игрового сохранения остаётся 36.

Повторный ID отвергается до заполнения каталога: следующая запись без
пищевого свойства или с ошибкой не может унаследовать съедобность предыдущей.
Исправление найдено финальным ревью и проверено отдельным RED→GREEN.

Пять прежних пар сытости/энергии закреплены непосредственно в тесте,
независимо от данных культур: ягоды 14/5, морковь 28/12, капуста 45/25,
картофель 30/10, клубника 20/8.

## Доказательство и проверки

Тестовая еда `test:ration` 17/0 определена только в отдельном JSON-каталоге.
Проверочная симуляция получает расширенный каталог; дополнительные проверки
не добавляют предмет в обычную игру. Открытие меню, питание из личного и
общего запаса, стол, реальные отказы и сохранение проверяются через настоящие
обработчики, без отдельного исключения для ID тестового предмета.

Новый тест свойств сначала сообщил три отсутствующих API, затем прошёл.
Сценовый тест действий сначала сообщил 15 нарушений контракта, затем прошёл.
Первоначальные ошибки подготовки самих тестов исправлены до принятия RED.
Дополнительно проверен продукт культуры без `food`: питание отказывается
без изменений состояния, а извлечение собственных семян остаётся доступным.
Целевые регрессии и их актуальный статус записаны в
[`checks.json`](../../artifacts/item-food-2026-10-11/checks.json).
После исправления замечаний финального ревью все 14 наборов завершились
с кодом 0, без `ERROR`/`SCRIPT ERROR`. Предупреждения миграции старых
сохранений ожидаемы в соответствующих тестах.
Хеши файлов `first_night_save.json` до и после проверок совпали; результаты
хранятся в [`save-check.json`](../../artifacts/item-food-2026-10-11/save-check.json).

Старый сценовый тест фермерства упал на границах скрытого контекстного меню
после изменения размера окна. Это воспроизведено на контрольном коммите
в отдельной копии проекта. Проверка теперь заново открывает тот же предмет
после обновления и требует видимость перед проверкой границ. Производственное
поведение UI не менялось. Логи до и после сохранены.

Новые стресс/FPS-прогоны не выполнялись. Корректность еды не подтверждает
устранение задержек кадров, баланс или удобство во всех игровых ситуациях.

## Продолжение

Это завершает перенос пищевых свойств, а не всю часть предметов и не весь
подготовительный этап. Следующий результат — варианты инструментов через
поддерживаемые возможности, с согласованной добычей, вспашкой, выбором NPC
и отображением в руках. Затем остаются влияния черт, временные эффекты и
условия/последствия разговоров; генератор карты следует после подготовки.

Переименование `FirstNightContent` записано как технический долг.
