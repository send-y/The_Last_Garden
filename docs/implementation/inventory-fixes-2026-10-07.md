# Инвентарь: поворот иконок и сохранение раскладки — 7 октября 2026

**Статус:** три проблемы из первого ручного прохода автора исправлены в рабочем дереве. Пауза большого производственного плана сохраняется; этот пакет выполняет конкретный запрос по найденным ошибкам.

## Что воспроизведено

1. `InventoryGrid` поворачивал занимаемую форму, но рисовал текстуру без поворота. Та же ошибка была в предпросмотре предмета в руке.
2. `InventoryAutoPacker` обходил предметы по каталогу: новый стак мог занять место ещё не обработанного инструмента. Сохранённая ручная раскладка учитывалась только при очередном предмете, поэтому инструмент перемещался. Позиции вновь добавленных стаков также не фиксировались при каждом изменении.
3. `_can_add_item` проверял вместимость на полностью заново упакованном рюкзаке. Такая упаковка могла не вместить топор, хотя текущая ручная раскладка оставляла место для древесины.

Для воспроизведения скриншота использована сетка 4×4: 40 древесины в восьми стопках, три шишки в клетке (0,2), топор с поворотом 1 и началом (1,2). Топор занимает пять клеток; остаются свободными (0,3) и (1,3). Они вмещают ещё десять единиц древесины двумя стопками по пять. Это расчёт вместимости конкретной раскладки, не изменение размеров рюкзака или стаков.

## Исправления

- Общий упаковщик сначала резервирует все действующие ручные позиции, затем ищет свободные клетки для новых стаков. Это сохраняет положения предметов независимо от порядка каталога.
- Проверка вместимости использует текущую раскладку. Проверка ручного перемещения тоже получает текущие размещения, а не независимую автоматическую сортировку.
- Перед уведомлением интерфейса об изменившемся состоянии симуляция фиксирует актуальную раскладку: новые позиции сохраняются для следующих действий и загрузки.
- Обычная иконка и иконка предмета в руке используют один способ рисования с поворотом вокруг центра. Для нечётного поворота размеры прямоугольника меняются местами, чтобы избежать растяжения. Изменение относится к всем предметам, использующим эту сетку, включая панель складской клетки.

Ошибочные/пересекающиеся сохранённые позиции по-прежнему могут исправляться нормализацией. Автоматическая перестановка корректно размещённых предметов при обычном подборе устранена. Формат сохранения не менялся; новая игра не требуется. Исправление не может восстановить позиции, которые пользователь уже потерял до обновления.
