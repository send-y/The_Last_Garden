# Пакет D и актуализация Mechanics Lab

> Исполнение: последовательно в текущем чате, superpowers:executing-plans.

Цель: безопасное продолжение мира, естественная первая встреча, помощь едой,
доски для общей стройки и актуальная лаборатория. Основа:
[передача контекста](../../handoffs/2026-10-14-package-d-context.md).

## Границы и решения

- Не менять чужой items.json, основной сейв, старые логи и кэши.
- 14 октября автор разрешил весь пакет и чистку устаревшего в лаборатории.
- Лучший доступный общий инструмент; сохранённый в серии подходящий инструмент
  не менять посреди работы. Личные инструменты игрок держит при себе.
- Мира делится реальной едой однократно, остаток при полном рюкзаке сохраняется.
  Короткое знакомство доступно голодным участникам; длинные темы сохраняют ограничения.
- Автор начинает заново. Одноразовая помощь также доступна знакомой Мире,
  без сброса памяти и повторной выдачи при загрузке.
- Нет доступного верстака — просьба, временно занят — ожидание.
- Согласовано: 18 порций core:food у Миры, до 10 игроку, 8 остаются ей.
  Это пробный баланс. Новое после D обсудить отдельно.
- Сценарии первой ночи убрать из обычного меню, если они устарели; совместимость
  с автоматическими регрессиями и диагностикой сохранить. FPS/стресс-замеры не запускать.

## Последовательность

- [x] D1. Архив фактического сейва с SHA256; изолированный путь Session для тестов;
  тест сохранности физических экземпляров, размещений, построек и прогресса
  после добавления предмета/рецепта; загрузка копии в лаборатории.
  Файлы: fixtures/package_d, save store, session, crafting catalog, run_checks.py.
- [x] D5. Отчёт и выбор лучшего общего инструмента по эффекту конкретного действия.
  Проверки: порядок склада, недостижимый/неподходящий экземпляр, сохранение серии.
- [x] D2/D3. Замеры рабочего дня до/после 0,33. Припасы Миры в данных,
  структурированная первая встреча и действие передачи; семантическая локализация.
  Проверки: оба голодны, полный рюкзак, частичный подарок, повторный вызов/загрузка,
  разные черты и крыша/еда, сохранность истории знакомого NPC.
- [x] D3b. Короткий отчёт по пяти вопросам Dialogue Manager из первичных источников.
  Не устанавливать зависимость.
- [x] D4a. Реальное производство досок для общих оплачиваемых чертежей,
  существующие контракты станций, запасов и рабочих серий.
  Проверки: входы/выходы, резерв, конкуренция, отмена, загрузка и завершение стройки.
- [x] D4b. Одна необязательная просьба о верстаке с причиной, ответом, памятью
  и паузой. Проверки: отсутствие условий, занятость, отказ, исполнение.
- [x] Lab. Актуальное меню и безопасные сценарии D; исторические сценарии доступны
  только для регрессий. Проверить загрузку всех обычных пунктов и UI.
- [x] Интеграция: основной набор, затронутые зависимости, графический UI,
  сценарий семи дней с фактическими метриками. Отдельно указать границы автоматики.
- [x] Обновить текущую документацию и журнал решений, локальные коммиты по этапам.

## Граница завершения

Реализация и перечисленные автоматические проверки выполнены. Приёмка игрового
баланса шире успешного теста: контроль не обеспечивает питание нового жителя
дня 3 и поздних дней, не строит новые полноценные комнаты и не доказывает темп
склада или удовольствие. Это остаётся открытой продуктовой проверкой, а не
поводом помечать весь баланс демо подтверждённым. Подробности в текущем отчёте.

Каждый логический этап: содержательный тест до изменения поведения, необходимый
прогон после, самопроверка diff и локальный коммит только файлов задачи.
Не расширять успешные проверки без новой причины.
