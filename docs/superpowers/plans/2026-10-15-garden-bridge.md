# Garden Bridge: implementation plan

Пользователь разрешил push готовых коммитов и разработку ранее предложенного
локального моста чтения состояния, ошибок, дерева UI и скриншотов.
Исходные 39 коммитов отправлены в origin/codex/storage-zones, HEAD 3c331c6.

## Контракт первой версии

Godot debug-autoload публикует отдельную сессию в `.garden_bridge/`.
Python 3.11 stdlib предоставляет MCP stdio и CLI без дополнительных пакетов.
IPC — ограниченные JSON-запросы/ответы в каталоге сессии, без сетевого порта.
Методы: list_sessions, get_state, inspect_tree, get_errors, capture_frame.
Несколько живых игр требуют явного session_id. Таймаут и heartbeat позволяют
отличать остановленную игру от живой. Нет eval, записи мира, загрузки сейва,
эмуляции ввода или доступа к произвольным файлам через параметры инструментов.

Снимок кадра сохраняет PNG, состояние и дерево UI с общим frame_id.
Logger хранит ограниченный буфер ошибок и backtrace; не перехватывает сам
себя рекурсивно. Headless честно отказывает в снимке. Runtime работает при
паузе; выключен в release и обычных тестах с --test-save-path. Отдельный
аргумент --garden-bridge-dir позволяет интеграционные проверки в изоляции.
Чтение не меняет симуляцию и не вызывает автосохранение.

## Выполнение

- [ ] RED: Python discovery/path/stdio tests и Godot runtime contract.
- [ ] Реализовать IPC, diagnostics, state/tree/capture и stdio tools.
- [ ] GREEN: живой MCP handshake, вызовы в headless и графической игре,
  screenshot inspection, stale/ambiguous session, запрет неизвестных методов.
- [ ] Настроить project MCP, документацию; свежий итоговый review и исправления.
- [ ] Локальный коммит, push и проверка remote HEAD. items.json не включать.

Проверки не запускают FPS/стресс-замеры. Дополнительный регрессионный прогон
выбирается по новой autoload-интеграции; обычные тесты должны оставаться без IPC.
Подключение нового MCP к текущему открытому чату может потребовать перезапуска
клиента; до этого мост проверяется настоящими stdio запросами и CLI.
