# Procedural Residents Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Постоянный генератор согласованных личностей и несколько живых NPC на текущей карте.

**Architecture:** Отдельные каталог компонентов, генератор профиля и реестр жителей.
Существующие потребности, работа, внешность и UI получают данные через общий реестр.
`WorldSimulation` остаётся фасадом; крупную новую логику не добавлять в него.

**Tech Stack:** Godot 4.7, типизированный GDScript, JSON-контент, версионированные сохранения.

**Spec:** [Согласованный дизайн](../specs/2026-10-08-procedural-residents-design.md).

## Global Constraints

- Первый этап спецификации. Совместное обустройство и резерв склада — следующий
  отдельный план; социальные события и конфликты — последующий этап.
- Не выдавать первый этап за реализацию всего согласованного направления.
- Сохранить Миру, её ID, старые состояния, имущество, работу и память.
- Не перегенерировать сохранённые профили при загрузке или обновлении контента.
- Истинные факты и решения хранятся в симуляции; без runtime AI.
- Сохранить существующие изменения рабочего каталога; без коммита и публикации.
- Существующее поведение ночлега, голода, работы и инструменты остаются реальными.
- Название `godot` в командах ниже обозначает найденный Godot 4.7 console executable.
  До выполнения найти фактический путь: сейчас наличие команды в PATH не подтверждено.

## Review Focus

1. Противоречивые компоненты: генератор завершает работу ошибкой, не зависает (задача 1).
   Также исключаются невозможный возраст, неподходящая технология и выдуманное
   личное участие в недатированном историческом событии.
2. Повторная загрузка и смена каталога: личность и ID не меняются (задачи 1–2).
3. Новый NPC есть в save, но нет в сцене/автономии/жилье: единый реестр (задачи 2–3).
4. Одновременные люди претендуют на место и инструмент: реальное совместное использование (задача 3).
5. Прерванный проект и незнакомый житель: устойчивое намерение и достоверная карточка (задачи 4–5).

**Interfaces (новые):**
- `NpcGenerationCatalog.validate() -> Array[String]`.
- `NpcProfileGenerator.generate(seed_value: int, npc_id: String, catalog: Dictionary) -> Dictionary`.
- Результат: `ok: bool`, `profile: Dictionary`, `reason_id: String`.

  воспоминания не объединяются в одно поле происхождения. У `history_facts`
  сохраняются факт и источник; `beliefs` не изменяют канон симуляции.

  обязательно другого результата для каждой пары seed; невозможный каталог
  завершает генерацию с `ok == false`.
- [x] Добавить лор-проверки на фикстурах: 28-летний житель не участвовал лично в

  в слишком короткую жизнь; неподдерживаемая технология исключена; нынешняя община
  может отличаться от культурного наследия. Числа здесь тестовые, не баланс игры.
- [x] Выполнить `godot --headless --path game --script res://tests/npc_generation_test.gd`,
  подтвердить отказ из-за отсутствующего API.
- [x] Реализовать валидацию компонентов и ограниченный согласованный выбор.

  Первые компоненты должны влиять на доступные полив/заготовку/стройку или выбор мебели.
  Следовать лор-последовательности из спецификации: возраст/община → наследие →
  детство → опыт → характер/интересы → причина пути/стремление → вещи → валидация.
  Не вводить названия держав, точные даты их падения и современную политическую
  карту как канон без отдельного основания в документации мира.

## Следующие самостоятельные планы

1. Собственное/совместное жильё: полномочия, личные зоны, пожелания соседей,
   расширение и атомарный расход материалов над неприкосновенным запасом.
2. Совместная история: фактические события, память, отношения между NPC,
   мягкие и принципиальные разногласия, ограниченные изменения привычек и целей.

## Проверка человеком

Провести несколько игровых дней с тремя процедурными жителями. До чтения полной
карточки описать каждого по поступкам; отметить повторяющиеся действия, непонятные
отказы и одинаковые проекты. Если различия видны только в описании, усилить поведение
первых компонентов перед расширением библиотеки и населения.
