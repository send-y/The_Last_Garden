# The Last Garden

The Last Garden — атмосферная 2D-игра сверху о небольшой ферме, которая постепенно становится живым поселением. Игрок остаётся отдельным человеком, а жители обладают собственными характерами, потребностями, отношениями, работой и памятью.

Проект находится на стадии предпроектного анализа. Реализация в Godot ещё не начата.
