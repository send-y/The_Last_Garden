# The Last Garden

The Last Garden — атмосферная 2D-игра сверху о небольшой ферме, которая постепенно становится живым поселением. Игрок остаётся отдельным человеком, а жители обладают собственными характерами, потребностями, отношениями, работой и памятью.

Предпроектный анализ и срез 1 «Первая ночь» завершены. Инкремент 2A «Присутствие и сохранение первого NPC», checkpoint L1 «Mechanics Lab» и checkpoint L2 «Фундамент локализации» слиты в `main`. Инкремент 2B «Потребности, движение и распорядок» открыт в отдельной рабочей ветке. Техническая готовность, автоматические проверки и ручной плейтест отслеживаются отдельно в дорожной карте.

## Запуск

Godot-проект находится в папке [`game`](game/README.md). Откройте `game/project.godot` в Godot 4.7 и запустите проект клавишей `F5` или кнопкой запуска проекта.
