[Дома жителей и защищённый запас](../docs/implementation/resident-homes-2026-10-08.md):
в назначении жилья выбирается личная, совместная или общая роль комнаты.
В своём доме житель обустраивает быт; в общем стартовом доме работает по чертежам
игрока. На складе появилась вкладка «Защищённый запас», а в «Планах» — причины
ожидания и просьбы о расширении. Быстрая проверка: «Механики [F2]» →
«Дома жителей и защищённый запас». Текущая версия сохранения — 34.

[Личные проекты NPC](../docs/implementation/npc-home-projects-2026-10-08.md):
назначьте жителю спальник/кровать, включите «Стройка» и откройте «Планы».
Житель обустраивает своё жильё столом, стулом и светом; положите необходимые
доски на доступный общий склад. Можно отклонить проект и разрешить его снова.

[Быт жителя](../docs/implementation/household-feedback-2026-10-08.md):
откройте карточку NPC — назначенный ночлег виден сразу. На вкладке «Быт»
показаны доступность еды, стула у стола и вечернего света, проблемы и способы
их решения. Назначить личную кровать или спальник можно из той же карточки.

[Полезная мебель](../docs/implementation/useful-furniture-2026-10-08.md):
подойдите к свободной стороне стула у стола и взаимодействуйте для еды
или отдыха. Начните движение, чтобы встать. Факелы переключаются
взаимодействием и освещают окружение вечером.

[Самостоятельная помощь NPC](../docs/implementation/npc-practical-work-2026-10-08.md):
в карточке знакомого жителя включаются полив, заготовка ресурсов и стройка.
Для работы нужны реальные общие инструменты, а для строительства — чертёж
и материалы на складе. По умолчанию эти возможности выключены.

Папка содержит запускаемый прототип постоянного мира на текущей карте для Godot 4.7 Standard и типизированного GDScript. [Модульная симуляция и непрерывный календарь](../docs/implementation/persistent-world-and-simulation-modules-2026-10-08.md) заменяют ограничение сценария первой ночи; восстановление дома остаётся введением и полезной прогрессией.

## Запуск

1. Открыть `project.godot` в Godot 4.7.
2. Запустить проект кнопкой **Run Project** или клавишей `F5`.

Текущий старт соединяет добычу древесины, строительство верстака, изготовление досок, закрытие кровли и восстановление энергии после сна. [Реализованный объём и проверки](../docs/implementation/roof-and-energy-increment-2026-10-05.md); темп и понятность маршрута ещё требуют ручного прохождения.

После старта доступно [повторяемое хозяйство](../docs/implementation/repeatable-farming-increment-2026-10-05.md): особые ягоды → случайные семена → грядка и полив → сырой урожай → собственные семена после постройки стола → повторный посев. В первом наборе морковь, капуста, картофель и клубника. Автоматического возврата семян при сборе больше нет.

## Mechanics Lab

Mechanics Lab — внутренняя debug-сцена для быстрой проверки механик без ожидания полного игрового дня. Она использует основную игровую сцену и ту же симуляцию, а не отдельную упрощённую копию игры.

Запуск лаборатории:

1. Открыть `res://src/dev/mechanics_lab.tscn` в редакторе Godot.
2. Запустить текущую сцену клавишей `F6`.
3. Открыть панель кнопкой **«Механики [F2]»** сверху экрана или клавишей `F2`; выбрать подготовленный сценарий, изменить время или сбросить текущий сценарий.

Повторное нажатие кнопки или `F2` закрывает панель. При запуске она свёрнута; начало разговора с NPC также сворачивает её, чтобы реплики оставались доступными для мыши.

Лаборатория доступна только в debug-сборке. Она предназначена для разработки и не является частью интерфейса игрока. Пока она активна, `F5`, `F9` и автосохранение не читают и не изменяют обычный файл сохранения.

## Управление

- `Shift + ПКМ` рядом с построенной стеной, мебелью или полом — разбор с возвратом 50% материалов; по ягодному кусту с топором в руке — постоянное удаление. Стартовые руины пока не разбираются.
- `ПКМ` или `E` по двери — открыть/закрыть; NPC открывают дверь при приближении.

- `WASD` или стрелки — движение;
- левая кнопка мыши — выбор объекта или клетки;
- правая кнопка мыши или `E` — взаимодействие;
- `I` — открыть или закрыть рюкзак; выбери экземпляр предмета и нажми `1`–`5`, чтобы назначить его в слот хотбара;
- `1`–`5` или щелчок по слоту — выбрать предмет хотбара;
- первый ЛКМ по предмету в рюкзаке — выбрать в руку персонажа и взять в курсор; второй ЛКМ — разместить, `R` — повернуть, ПКМ — отменить; ПКМ по лежащему предмету открывает действия;
- с выбранным ведром взаимодействуй с клеткой воды у берега, чтобы наполнить его;
- выбери особые ягоды в рюкзаке и нажми «Семена»; после постройки стола это действие работает и для продуктов культур;
- с выбранной мотыгой взаимодействуй с свободной землёй; повторное взаимодействие с грядкой открывает посадку, полив и сбор;
- для полива выбери наполненное ведро перед открытием грядки; влажность действует 24 игровых часа;
- `Space` — пауза;
- `F5` — сохранение;
- `F9` — загрузка.

## Локализация

Исходный каталог находится в `localization/core.csv`. Сейчас заполнен только базовый русский столбец `ru`; русский также является fallback-языком проекта. Игровые JSON и симуляция используют стабильные ключи, а видимые строки собираются в `Session` и HUD.

Файлы `*.translation` создаёт импортёр Godot. Редактировать нужно CSV, сохраняя его в UTF-8 без BOM. Новые языки позднее добавляются столбцами без изменения игровых ID и ключей.

## Headless-проверки

Жильё проверяется отдельно:

```powershell
godot --headless --path game --script res://tests/housing_sleep_test.gd
godot --headless --path game res://tests/housing_ui_test.tscn
```

Из папки репозитория:

```powershell
godot --headless --editor --path game --quit
godot --headless --path game --script res://tests/run_tests.gd
godot --headless --path game --script res://tests/farming_rules_test.gd
godot --headless --path game --script res://tests/persistent_world_test.gd
godot --headless --path game res://tests/persistent_world_integration_test.tscn
godot --headless --path game res://tests/farming_integration_test.tscn
godot --headless --path game res://tests/npc_collision_integration_test.tscn
godot --headless --path game res://tests/inventory_close_integration_test.tscn
godot --headless --path game res://tests/crafting_integration_test.tscn
godot --headless --path game res://tests/boulder_depth_integration_test.tscn
godot --headless --path game res://tests/room_designation_integration_test.tscn
godot --headless --path game res://tests/resource_access_integration_test.tscn
godot --headless --path game res://tests/resource_guidance_integration_test.tscn
godot --headless --path game res://tests/roof_sleep_energy_integration_test.tscn
godot --headless --path game --quit-after 3
godot --headless --path game res://src/dev/mechanics_lab.tscn --quit-after 3 -- --lab-scenario=fresh_start
godot --headless --path game res://src/dev/mechanics_lab.tscn -- --lab-scenario=bucket_hotbar
```

Первый вызов импортирует исходные ресурсы, включая CSV локализации. Второй проверяет симуляцию, миграции сохранений, каталог локализации, сценарии лаборатории и обычный хозяйственный путь до второго урожая. Farming rules отдельно проверяют три режима урожая, семена, сухость и сохранения; farming integration — настоящие кнопки и взаимодействия основной сцены. GUI-сцена инвентаря также проверяет назначение ведра в хотбар и наполнение у берега без выдачи сырой воды. Отдельный сценарий `bucket_hotbar` содержит два ведра с разным запасом и ставит игрока у доступного берега. В текущей обычной новой игре пустое ведро, топор, кирка и мотыга находятся в стартовой кладовой; это покрывает `starting_pantry_integration_test`. Полив грядок выбранным ведром реализован. Тестовый сценарий не является временной кнопкой обычного HUD.
