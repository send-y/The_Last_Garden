# Первый вертикальный срез

Папка содержит запускаемый прототип «Первой ночи» для Godot 4.7 Standard и типизированного GDScript.

## Запуск

1. Открыть `project.godot` в Godot 4.7.
2. Запустить проект кнопкой **Run Project** или клавишей `F5`.

## Управление

- `WASD` или стрелки — движение;
- левая кнопка мыши — выбор объекта или клетки;
- правая кнопка мыши или `E` — взаимодействие;
- `Space` — пауза;
- `F5` — сохранение;
- `F9` — загрузка.

## Headless-проверки

Из папки репозитория:

```powershell
godot --headless --path game --script res://tests/run_tests.gd
godot --headless --path game --quit-after 3
```

Первый вызов проходит полный упрощённый сценарий ночи на уровне симуляции. Второй проверяет загрузку основной сцены. Временная графика предназначена только для проверки управления, масштаба и игровых систем.
