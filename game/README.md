# Первый вертикальный срез

Папка содержит запускаемый прототип «Первой ночи» для Godot 4.7 Standard и типизированного GDScript.

## Запуск

1. Открыть `project.godot` в Godot 4.7.
2. Запустить проект кнопкой **Run Project** или клавишей `F5`.

## Mechanics Lab

Mechanics Lab — внутренняя debug-сцена для быстрой проверки механик без ожидания полного игрового дня. Она использует основную игровую сцену и ту же симуляцию, а не отдельную упрощённую копию игры.

Запуск лаборатории:

1. Открыть `res://src/dev/mechanics_lab.tscn` в редакторе Godot.
2. Запустить текущую сцену клавишей `F6`.
3. Выбрать подготовленный сценарий, изменить время или сбросить текущий сценарий через панель разработчика.

Лаборатория доступна только в debug-сборке. Она предназначена для разработки и не является частью интерфейса игрока. Пока она активна, `F5`, `F9` и автосохранение не читают и не изменяют обычный файл сохранения.

## Управление

- `WASD` или стрелки — движение;
- левая кнопка мыши — выбор объекта или клетки;
- правая кнопка мыши или `E` — взаимодействие;
- `Space` — пауза;
- `F5` — сохранение;
- `F9` — загрузка.

## Локализация

Исходный каталог находится в `localization/core.csv`. Сейчас заполнен только базовый русский столбец `ru`; русский также является fallback-языком проекта. Игровые JSON и симуляция используют стабильные ключи, а видимые строки собираются в `Session` и HUD.

Файлы `*.translation` создаёт импортёр Godot. Редактировать нужно CSV, сохраняя его в UTF-8 без BOM. Новые языки позднее добавляются столбцами без изменения игровых ID и ключей.

## Headless-проверки

Из папки репозитория:

```powershell
godot --headless --editor --path game --quit
godot --headless --path game --script res://tests/run_tests.gd
godot --headless --path game --quit-after 3
godot --headless --path game res://src/dev/mechanics_lab.tscn --quit-after 3 -- --lab-scenario=fresh_start
```

Первый вызов импортирует исходные ресурсы, включая CSV локализации. Второй проверяет симуляцию, миграции сохранений, каталог локализации и сценарии лаборатории. Третий проверяет загрузку основной сцены, четвёртый — загрузку Mechanics Lab с выбранным сценарием. Доступные ID: `fresh_start`, `prepared_evening`, `morning_with_mira` и `mira_resting`. Последний сценарий сразу открывает поздний вечер после детерминированно прожитого дня Миры. Эти автоматические проверки пройдены. Временная графика предназначена только для проверки управления, масштаба и игровых систем.
