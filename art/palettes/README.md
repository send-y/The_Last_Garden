# The Last Garden palettes

В проекте есть две палитры: основная на 54 цвета и расширенная на 72 цвета. Расширенная сохраняет базовые цвета и добавляет отдельные шкалы здоровья, энергии и информационных акцентов для UI. Исходные файлы в Git — источник истины; установочная копия находится в каталоге расширений Aseprite.

## Правила

- Не обязательно использовать все цвета в одном спрайте. Для небольшого объекта обычно достаточно 4-8.
- Выбирай соседние цвета внутри одной шестицветной шкалы; цвета из других шкал добавляй только по назначению.
- Источник света всегда сверху-слева. Нижняя и правая стороны объекта темнее.
- Цвет `Ink` применяй для самых глубоких щелей и UI, но не обводи им автоматически каждый объект.
- Чистого чёрного и чистого белого в палитре нет: это сохраняет мягкий, природный тон игры.
- Деревянная шкала сохраняет все шесть цветов первого спрайта бревна `log_sprite.png`.
- Для HUD используй здоровье только в шкале `Health`, энергию — в `Energy`, а teal-акценты — редко, для информационного фокуса.

## Шкалы

1. Neutral and interface — глубокие тени, текст, панели, светлые нейтрали.
2. Soil and dry landscape — почва, глина, песок, солома.
3. Wood — кора, доски, брёвна, свежий спил.
4. Living greens — трава, деревья, мох, весенняя растительность.
5. Crops and autumn — зерно, сухие растения, осень.
6. Water, rain and cold light — вода, дождь, лёд, холодный свет.
7. Stone and metal — камень, руда, тусклый металл.
8. Skin and leather — оттенки кожи и кожи как материала.
9. Cloth, berries, fire and attention — одежда, ягоды, огонь и редкие акценты.
10. Health — сердце, здоровье и урон.
11. Energy — энергия и тёплые игровые подсказки.
12. Information and focus — информационные состояния и мягкие акценты UI.

## Файлы

- `the-last-garden-54.gpl` — исходная основная палитра.
- `the-last-garden-72.gpl` — расширенная палитра для UI и спрайтов, которым нужны дополнительные сигнальные цвета.
- `package.json` — описание расширения Aseprite с обеими палитрами.
