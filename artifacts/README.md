# Свидетельства проверок и разработки

Каталоги с датами содержат логи, результаты проверок, скриншоты и вспомогательные
скрипты отдельных инкрементов. Это исторические записи: логи `red`, `before`,
`baseline`, ошибки в ранних запусках и старые результаты не описывают автоматически
состояние текущей версии. Некоторые скрипты привязаны к локальным путям автора.

Свежая проверка перед публикацией вехи NPC находится в
[`checkpoint-2026-10-10`](checkpoint-2026-10-10/verification.json).
Её runner принимает путь к Godot:

```powershell
python artifacts/checkpoint-2026-10-10/verify.py --godot '<путь к Godot console.exe>'
```

Он запускает существующие самостоятельные тесты, тестовые сцены и запуск основной
сцены. Проверки пикселей используют графический рендерер; остальные — headless.
Успешные тесты подтверждают проверенные контракты, но не баланс, удовольствие
от игры или отсутствие просадок FPS в длительной игровой сессии.
